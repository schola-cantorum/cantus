要決定的事

這份報告回答：epic 0001 交付了什麼、證據是什麼，以及它現在能不能關。關閉之後才進入 v0.7.0 的發版流程與下一個 epic。

交付內容

  • 公開 API 由 Skill 改名為 Tool：Tool、@tool、register_tool()、Registry(tools=[...])、Agent(model, tools=[...])，事件類別改為 CallToolAction、ToolObservation。
  • 別名過渡期：W1–W18 的舊名稱仍可用，並發出 CantusDeprecationWarning；舊的 HTTP 路由保留，回應帶 Deprecation 與 Link header。
  • 沒有別名的變更：X1–X12 等項目直接改變行為或丟出錯誤，例如事件類別名稱、Registry.KINDS、_dispatch_skill 的改名。這些是 breaking change，列在遷移指南。
  • cantus serve 與 TUI：新增 /tools 路由家族，TUI 分頁改為 Tools。
  • 文件：文件網站、根目錄文件與 notebook 的內文改用 Tool API；notebook 的安裝版本仍釘在 v0.6.0，要到發版時才更新。新增 v0.6.0 → v0.7.0 遷移指南（70 個條目）、CHANGELOG 的 [Unreleased]，以及 ludus 的遷移文件。
  • 持續把關：tests/test_rename_sweep.py 在 CI 擋下標記區以外的舊名稱。

規模：15 張票、15 個 PR（#57–#71），259 個檔案、+27,729／−3,118 行，其中 cantus/ 與 tests/ 佔 115 個檔案、+13,353／−1,655 行。套件版本仍是 0.6.0，尚未發行。
