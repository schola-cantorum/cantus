交付內容

  • 公開 API 由 Skill 改名為 Tool：Tool、@tool、register_tool()、Registry(tools=[...])、Agent(model, tools=[...])，事件類別改為 CallToolAction、ToolObservation。
  • 別名過渡期：舊名稱仍可用，並發出 CantusDeprecationWarning（W1–W18）；舊的 HTTP 路由保留，回應帶 Deprecation 與 Link header。
  • cantus serve 與 TUI：新增 /tools 路由家族，TUI 分頁改為 Tools。
  • 文件：文件網站、根目錄文件、notebook 全面改用 Tool API；新增 v0.6.0 → v0.7.0 遷移指南（70 個條目）與 CHANGELOG 的 [Unreleased]；ludus 的遷移文件。
  • 持續把關：tests/test_rename_sweep.py 在 CI 擋下標記區以外的舊名稱。

規模：15 張票、15 個 PR（#57–#71），259 個檔案、+27,729／−3,118 行，其中 cantus/ 與 tests/ 佔 115 個檔案、+13,353／−1,655 行（git diff --shortstat cd89257..6a92ab8，由彙整的 agent 執行）。套件版本仍是 0.6.0，尚未發行。
